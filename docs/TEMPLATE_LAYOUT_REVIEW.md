# 홈·어바웃 구성 개선 · 2026-09-12

## 기준과 참고

승인된 텍스트와 MOKDA의 크림·브라운·오렌지 콘셉트를 유지하면서 섹션별 구성과 움직임을 정리했다.

- 아임웹 공식 템플릿 목록: https://imweb.me/theme
- FreshGrove 공식 미리보기: https://cdn.imweb.me/upload/21fa5f89f6d13.png
  - 큰 음식/제품 비주얼, 제품 그리드, 사진과 설명의 분할 구성을 참고.
- PICK 공식 미리보기: https://cdn.imweb.me/upload/d61058e27e5f5.png
  - 큰 제목, 사진 크기에 따른 정보 우선순위, 넉넉한 여백을 참고.

공식 미리보기 이미지를 직접 확인했다. 템플릿의 실제 애니메이션을 확인하거나 복제한 것은 아니며, 사진·카피·코드는 가져오지 않았다. 카페24 공식 카탈로그도 검색했지만 구체적인 적용 근거는 위 아임웹 미리보기다.

## 적용

- 공통: 본문 최대 폭, 좌우 여백, 섹션 간격, 제목 크기를 공유한다.
- 홈: 제품 2열 → 큰 대표 음식 사진과 작은 보조 사진 → 현장 사진 콜라주 → 추천사 → 공개형 FAQ → 문의 순서에 각기 다른 배치 리듬을 적용했다.
- 제품 카드의 아치형 모서리를 없애고 사진을 직사각형으로 정리했다.
- 현장 사진은 자연 비율로 표시하고 인물을 자르지 않는다.
- 추천사는 상자 대신 가는 구분선으로, 문의 버튼은 원형 대신 일반적인 필 형태로 정리했다.
- 어바웃: 스토리 본문/사진, 로고/설명, 인물 사진/연혁을 번갈아 배치한다. 모바일은 읽는 순서대로 쌓인다.
- 움직임: 해당 구간에 들어왔을 때 한 번만 짧게 나타나는 효과. 텍스트와 사진에 같은 속도 곡선을 쓰되 이동 거리와 지속 시간을 구분했다. 무한 반복, 자동 넘김, 추가 제어 버튼은 없다. 시스템 움직임 줄이기 설정을 존중하며 자바스크립트가 없어도 내용은 표시된다.
- 모바일 최종 검수 중 기존 문의 영역 스타일의 색상 충돌을 수정했다. 진한 배경 위 제목/설명은 크림색, 보조 제목은 밝은 오렌지, 버튼은 크림색 바탕으로 구분된다.

## 보존

- 작업 전 백업과 홈/어바웃 인라인 스크립트가 동일함을 비교했다. 승인된 KR/ES/EN 텍스트와 연혁 데이터는 변경하지 않았다.
- 새 버튼이나 리뷰를 추가하지 않았다. 기존 CTA 목적지는 유지한다.
- 제품 상세 페이지의 음식 사진 전용 구성과 승인된 Para Carnes 문구를 유지했다.

## 검수

- 모바일 390×844: 한국어 홈 첫 화면/현장, 스페인어 음식/FAQ/문의 및 어바웃 연혁, 영어 어바웃 스토리 직접 확인.

- 확인한 화면에서 이미지 로드 실패와 가로 넘침 없음.

## 사진 정렬 후속 수정 · alignment4

아래 이력 중 홈의 2단 현장 사진 구성은 다음 `grid7` 수정으로 대체되었다. 어바웃의 사진/제목 묶음은 유지한다.

사용자 스크린샷에서 확인된 비정형 공백과 사진/본문의 분리를 수정했다.

- 홈 현장 사진: 세로 사진 2장을 원본 비율에 맞는 4:3 열 너비로 나란히 놓고 회의 사진을 아래 전체 폭에 배치. 위쪽 사진의 높이가 일치하며 왼쪽 아래 구멍이 사라진다.
- 모바일 아이덴티티: 로고를 제목 옆에 배치하고 설명을 전체 폭으로 표시. 설명 아래에 로고만 따로 남던 구성을 제거했다.
- PC 연혁: 사진을 왼쪽 열 전체 폭으로 표시하고 본문과의 열 간격을 줄였다. 사진의 원본 비율과 인물 전체는 유지한다.
- 모바일 연혁: 한 해의 연혁인 현재 데이터에서는 제목·연도·사진이 상단 하나의 묶음이 된다. 여러 연도로 확장될 때는 일반 세로 구성으로 돌아간다.
- 시제품: 128px(모바일 96px) 사진을 해당 출시 문구 옆에 배치하고 전체 묶음의 최대 폭을 제한했다.
- 한국어 500px 아이덴티티, 한국어 1280px 연혁, 스페인어 390px 연혁/시제품, 한국어 390px 홈 현장 사진을 직접 검수. 모바일에서 가로 넘침·이미지 오류 없음, 연혁 8개 유지.
- about.html은 직전 백업과 비교해 스타일시트 버전 외 변경 없음. 다국어 생성·분석 회귀 14개·타입 검사 통과.

## 일정한 사진 배열과 간장 제외 · grid7

추가 사용자 피드백에 따라 서로 다른 사진 크기로 만든 공백을 줄이고 기본 그리드로 정리했다. 아임웹 FreshGrove와 PICK 공식 미리보기를 다시 직접 확인했다. FreshGrove의 같은 크기 제품 배열과 PICK의 사진 행 구성을 참고했고, 카페24는 카탈로그 검색만 수행했다.

- 음식 소개: K-PEÑO와 Para Carnes를 PC 동일 크기 2열, 모바일 동일 폭 1열로 배치. 사진 아래 설명 위치를 통일하고 캡션 위 불필요한 선을 제거했다.
- 현장 소개: 제목/설명 아래에 세 사진을 같은 높이의 한 행으로 표시. 원본 비율을 유지하므로 사람을 자르지 않는다. 모바일은 두 세로 사진과 아래 회의 사진으로 구성한다. 수치 영역도 전체 사진 행과 같은 폭으로 표시한다.
- 간장 출시 전 제외 요청: 홈 제품 카드/음식 소개, 제품 상세, 전 언어 메뉴에서 간장을 제외했다. 관련 FAQ와 제품 메타 설명도 두 제품 기준으로 최소 수정했다. 이미지 자산과 과거 분석 데이터는 유지한다.
- 간장 안내 줄 자체가 사라져 그 위에 겹치던 구분선도 제거되었다.
- PC 1280px에서 음식 사진 동일 크기, 현장 사진 356~357px 높이 및 인물 전체 표시 확인. 모바일 390px에서 스페인어 음식 소개와 영어 제품 상세 확인. 분석 회귀 14개, 타입 검사, 수정 스크립트 문법 검사 통과.
- 기존 브랜드 콘셉트, 나머지 승인 문구, 어바웃 연혁 내용과 문의 기능은 유지. 로컬 미리보기 작업이며 공개 배포 없음.
