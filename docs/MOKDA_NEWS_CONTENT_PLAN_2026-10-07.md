# MOKDA 홈페이지 소식·영상 콘텐츠 구성 제안

조사일: 2026-10-07 (한국 시간)
범위: Google Drive MOKDA SNS 파일 구성, 현재 홈페이지 원본 코드, 식품·소스 브랜드 공식 홈페이지 사례.
상태: 조사·기획안. 홈페이지 구현 및 공개 반영은 하지 않음.

## 1. 추천 결정

상단 메뉴에 **MOKDA 소식 / Novedades MOKDA / MOKDA Updates**를 추가한다.

하나의 목록 안에서 **소식·미디어 / 행사 / 콜라보**를 구분한다. 사진과 영상이 보이는 카드 목록과 개별 상세 페이지를 기본으로 한다. 바이어는 실제 시장 활동과 외부 노출을 확인하고, 소비자는 제품을 즐기는 사람과 현장 분위기를 볼 수 있게 구성한다.

‘뉴스룸’도 가능한 명칭이다. 다만 현재 콘텐츠는 공식 보도자료뿐 아니라 행사 기록·체험 영상이 상당 부분이므로, MOKDA 소식이라는 넓은 이름을 우선 추천한다. ‘기업 소식’은 소비자 협업을 담기에 범위가 좁고, ‘보도자료’는 브랜드 자체 기록과 외부 보도를 구분하기 어렵다. 이는 아래 사례를 바탕으로 한 MOKDA용 판단이다.

| 역할 | 한국어 | 스페인어 | 영어 |
|---|---|---|---|
| 메뉴·페이지 | MOKDA 소식 | Novedades MOKDA | MOKDA Updates |
| 전체 필터 | 전체 | Todo | All |
| 브랜드 활동·외부 보도 | 소식·미디어 | Noticias y medios | News & Media |
| 박람회·소비자 행사 | 행사 | Eventos | Events |
| 크리에이터 협업 | 콜라보 | Colaboraciones | Collaborations |

보조 설명 제안:

- 한국어: 박람회부터 크리에이터 협업까지, MOKDA가 사람들을 만나는 현장을 소개합니다.
- 스페인어: Ferias, eventos y colaboraciones que conectan MOKDA con nuevas personas.
- 영어: Discover MOKDA at trade shows, events and creator collaborations.

## 5. 화면 구성

### 메인 홈페이지

현재 메인에는 제품 소개, 현장 스토리(proof), FAQ, B2B 문의, 후기(voices)가 있다. 새 소식 미리보기는 현장 스토리 다음에 배치하는 것을 추천한다.

대표 카드 3개를 노출한다:

1. Expoalimentaria 2026
2. KPOP STYLE 현장
3. 크리에이터 콜라보

각 카드에는 대표 사진, 분류, 제목, 설명 1~2줄, 상세 보기 링크를 둔다. ‘모든 소식 보기 / Ver todas las novedades’로 전체 목록에 연결한다. 기존 후기 영역은 유지하고 콜라보와 중복되는 콘텐츠만 편집 과정에서 정리한다.

### 전체 소식 페이지

- 상단: 제목과 짧은 소개.
- 분류: 전체 / 소식·미디어 / 행사 / 콜라보.
- 목록: 모바일 1열, 데스크톱 3열 사진 카드.
- 대표 게시물: 박람회 기록 1개를 먼저 강조.
- 정렬: 게시일 기준 최신순. 행사일은 별도 표시.
- 콜라보: 세로 영상을 보여주는 별도 구성 또는 컬렉션 상세에 묶어 영상 원래 비율 유지.

### 상세 페이지

제목 → 분류·게시일·행사일·장소 → 대표 이미지 → 핵심 요약 → 대표 영상 → 짧은 본문과 사진 4~8장 → 출처·크리에이터 표기 → 관련 제품·문의 → 관련 소식 순서를 추천한다.

목록에서 영상 여러 개를 동시에 자동 재생하지 않는다. 썸네일과 재생 버튼을 먼저 보여주고 선택 시 로드한다. 기존 브랜드 오렌지·크림·다크 브라운과 헤더를 이어 쓴다.

## 6. 구현 범위 제안

첫 버전은 기존 정적 홈페이지에 맞춰 목록·상세 템플릿과 콘텐츠 데이터를 추가한다. 지금은 관리자 시스템이나 Google Drive 자동 게시 연동을 먼저 만들 필요가 없다. 파일을 드라이브에 올리는 것과 공개 가능한 콘텐츠를 선별하는 것은 별도 단계다.

필요 기능:

- 공통 헤더의 소식 메뉴와 모바일 메뉴 연결.
- 분류 필터, 대표 소식, 목록·상세 링크.
- 한국어·스페인어·영어 제목·본문·메타정보.
- 영상 썸네일, 클릭 후 재생, 자막.
- 제품 링크, 문의 CTA, 관련 소식.
- 개별 공유 URL과 공유 이미지.

구현 메모:

- 정적 원본과 공통 스크립트가 현재 수정 대상이다. Next.js 영역을 자동으로 원본으로 간주하지 않는다.
- 다국어 생성기와 언어 전환의 경로 규칙에 새 목록·상세 경로를 반영한다.
- 현재 페이지 CSP에는 frame-src 'none'이 있으므로 외부 영상 임베드를 선택하면 해당 출처만 허용하도록 수정·검증해야 한다.
- 영상은 최적화된 MP4 또는 확인된 공개 영상 서비스의 임베드를 선택한다. Drive 공유 링크는 원본 관리용으로 유지하며 공개 권한을 임의 변경하지 않는다.
- 콘텐츠별 id, category, publishedDate, eventDate, location, 각 언어 제목·요약·본문, 대표 이미지, 영상, 출처, 크리에이터, 관련 제품 정보를 관리한다.
- 행사일과 게시일, 협업 영상과 자발적 후기, 미팅과 계약 성과를 구분한다.

구현 시 검증: 다국어 생성·관련 기존 검사, 모바일/데스크톱 목록·상세, 필터·키보드 조작, 영상 재생·자막, 언어 전환, 제품·문의 링크, 공유 메타, 가로 스크롤, 네트워크·콘솔 오류. 로컬·미리보기에서는 분석 전송을 비활성화한다.

- 방문과 미팅은 사실 그대로 설명한다. 공식 추천·인증·파트너십·수출 계약으로 확대 표현하지 않는다.

## 8. 조사 결과의 한계

자료 수량과 파일명은 커넥터 목록으로 확인했고, 레퍼런스의 메뉴·게시물 구성은 공식 웹 페이지로 확인했다. 현재 홈페이지 구성은 로컬 원본 코드 기준이며 공개 페이지의 실시간 전체 시각 검증은 완료하지 않았다. 영상 전편 검수·대표 장면 선정·최종 기사 작성·기능 구현은 이 조사 다음 단계다.
