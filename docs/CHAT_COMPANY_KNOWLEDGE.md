# MOKDA 챗봇 회사 지식

기준일: 2026-10-12. 대표님이 네 차례의 질문에 답한 회사 운영 기준을 정리했다.

운영 원본은 `site-company-knowledge.js`다. 한국어·스페인어·영어의 안내 문구와 확인된 사실을 함께 관리한다. 홈페이지의 기본 안내와 Cloudflare AI는 같은 원본을 사용한다.

| 항목 | 고객에게 안내할 기준 |
|---|---|
| 기본 MOQ | 1,000개. 제품별 수량·혼합 구성은 거래별 협의 |
| 가격 | 국가·수량을 확인한 뒤 개별 견적 |
| 출고 일정 | 주문별 협의 |
| 샘플 | 협의 후 50개 미만. 샘플 제품 자체는 1회 무료, 국제 배송비는 바이어 부담 |
| 포장 | 330 g 제품은 박스당 12개 |
| B2B 대용량 | 가능하며 용량은 협의 |
| 바이어 자료 | 제품 소개서·카탈로그는 스페인어. 원재료·영양성분표·시험자료 등은 영어 |
| 인증 | 관련 인증이 있다는 대표님 확인을 반영. 특정 인증의 종류·적용 범위는 담당자 확인 |
| 담당자 상담 | 한국어·스페인어. 문의는 언제든 접수하며 한국과의 시차로 답변이 늦어질 수 있음 |
| OEM·프라이빗라벨 | 별도 상담·검토 |
| 독점 유통 | 국가·지역별 제안 접수 가능. 계약 여부와 조건은 협의 |
| 개발 과정 | 중남미 시장을 겨냥해 중남미 셰프와 공동 개발. 현지 소비자를 대상으로 여러 차례 관능평가 진행 |

제품 내용량 330 g, 대한민국 원산지, 제조일부터 12개월이라는 정보는 기존 제품 상세 페이지에서도 확인했다. 실제 제품의 소비기한·표시사항은 패키지에 따른다.

## 답변 문체

MOKDA가 직접 설명하는 문장으로 답한다. 예를 들어 “제품 소개 자료에는 상온 보관으로 안내돼 있습니다” 대신 “개봉 전에는 상온에 보관하고, 개봉 후에는 냉장 보관해주세요”라고 안내한다. AI라는 사실은 상담창에 표시하며 사람이 상담 중이라고 표현하지 않는다.

조건이 정해지지 않은 거래는 “협의” 또는 “담당자 확인”으로 안내한다. 직접 설명하는 문체가 즉시 출고·재고·계약 체결·섭취 안전 등을 보장한다는 의미는 아니다.

## 정보의 범위

- 샘플은 **50개 미만**이다. 50개 이하로 바꾸거나 모든 신청자에게 자동 제공을 약속하지 않는다.
- 국제 운임 외 관세·통관비·세금의 부담 주체는 정해지지 않았다.
- 기본 MOQ와 박스당 수량을 근거로 1,008개로 자동 올림하지 않는다. 실제 포장 단위는 협의한다.
- 자료의 언어를 확대하거나 다운로드 링크를 임의로 만들지 않는다.
- 인증명·번호·유효기간·제품 또는 공장 적용 범위는 확인되지 않았다. 특정 인증 질문에 임의로 긍정하지 않는다.
- 시장 전체의 비교 근거가 없는 “유일한 브랜드” 표현은 고객 안내에 사용하지 않는다. 확인한 개발 과정으로 차별점을 설명한다.

## 갱신 방법

1. 운영 원본의 사실과 세 언어 안내를 함께 수정하고 확인일을 갱신한다.
2. 다국어 홈페이지를 생성한 뒤 `workers/mokda-chat/scripts/generate-knowledge.mjs`로 AI 자료를 생성한다. 제품 정보의 용량·기한·원산지 같은 `<dl>` 항목도 포함한다.
3. 상담 흐름·AI 계약 검사를 실행하고 홈페이지와 AI 서버를 함께 배포한다.
4. 운영 사이트에서 질문·응답과 공식 WhatsApp 연결을 검증한다.

원문 답변과 내부 검토 메모는 Git에서 제외된 `output/chat-knowledge/intake.json`에 보관한다. 공개 지식 생성기는 이 원문을 읽지 않는다. 새 고객 상담을 통해 회사 지식이 자동으로 바뀌지는 않는다.
