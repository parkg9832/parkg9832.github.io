# Website QA — 2026-09-22

## Coverage

- Languages: Spanish, Korean, English.
- Pages per language: home, about, products, K-PEÑO detail, Para Carnes detail, FAQ, contact (21 documents).
- Chromium viewport checks: 320×740, 390×844, 430×932, 768×1024, 844×390, 1024×768, 1280×800, 1440×900, 1920×1080 (189 combinations).
- Checked rendered overflow, heading bounds, loaded image failures, page heading count, navigation and console output. Horizontal review strips and screen-reader-only elements were excluded from element overflow detection.
- Selected mobile and desktop sections were also inspected visually, including home, history, testimonials, FAQ and detail artwork.

## Changes

- Reduced narrow-screen home and products headings to prevent clipping; corrected the mobile history grid and desktop history title sizing.
- Preserved inquiry product, purpose, campaign parameters and section anchors when switching language.
- Removed a reload handler that forcibly reset scrolling for 900 ms; native browser restoration now applies.
- Kept focus within the open mobile menu and made background content inert until it closes.
- Reserved product-detail image dimensions, preserved pre-rendered image nodes and lazy-loaded the eight images below the opening image.
- Corrected the K-PEÑO detail inquiry URL to the existing accepted `original` product identifier.
- Matched FAQ usage descriptions to the approved product copy and replaced outdated detail-availability wording.
- Corrected email/WhatsApp input hints, increased mobile field text to 16 px and improved inquiry button contrast.

## Results

- All 189 viewport combinations passed the final rendered geometry and loaded-image checks.
- Both detail sequences in all three languages loaded all 54 images when traversed; intrinsic dimensions matched.
- Fifteen desktop/mobile menu scenarios passed, including opening, closing and background restoration; keyboard wrapping and Escape focus restoration were checked separately.
- Internal integrity checks passed: 258 internal links and 66 distinct referenced assets.
- `generate:i18n`, `test:seo`, `test:analytics`, `test:security`, `test:navigation`, `test:integrity`, `typecheck` and `git diff --check` passed.
- No dependencies were added.

## Limits

Viewport testing used Chromium emulation, not physical iOS/Android devices or Safari. The contact form was checked for input validation and language/product preservation without sending a production inquiry or notification. Security regression checks do not constitute a penetration test.
