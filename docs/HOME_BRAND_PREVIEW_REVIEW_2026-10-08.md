# 메인 브랜드 히스토리 미리보기 검수

- 범위: 홈 `#proof`만 재구성. 브랜드 소개 페이지의 본문과 레이아웃은 유지.
- 기존 고추밭·제조 현장 사진 두 장을 제거하고, 기존 대표 부스 사진을 전체 배경으로 사용. CSS 흐림·갈색 오버레이로 글의 대비 확보. 사진 원본은 수정하지 않음.
- 제목과 소개는 가운데 정렬. 2024 아이디어, 2025 소스 개발, 2026 페루 Expoalimentaria의 세 기록과 기존 `about.html#history` 연결 제공.
- 최종 제목은 “한국의 맛을, 일상의 식탁으로”. 원료 검토와 맛 개발을 통해 한국의 맛을 라틴아메리카의 일상에 전한다는 소개로 정리. 영어·스페인어도 같은 의미로 수정.
- 한국어·영어·스페인어 원본 문구를 수정하고 42개 다국어 페이지를 다시 생성.
- 원본 `about.html`은 변경 없음. 생성된 브랜드 소개 문서는 공통 자산 캐시 해시를 제외하면 본문 DOM이 HEAD와 동일함을 비교 확인.
- 하인즈 [Our Story](https://www.heinz.com/our-story)의 실제 브라우저 화면에서 사진과 연도 위계를 참고. 참고 사이트의 문구·이미지는 사용하지 않음.
- Superdesign에 현재 섹션 버전 1, 개선 섹션 버전 2, 최종 문구 버전 3 저장. 동일 draft `a6df97f2-5800-440b-944a-ce7dae0bf02e`를 다시 조회해 사진과 문구 저장 확인.

검증:

- `generate:i18n`, `test:analytics` 14개 시나리오, `typecheck`, `test:seo`, `test:navigation`, `test:integrity` 통과.
- 실제 브라우저에서 3개 언어의 1440px·390px 확인. 한국어와 영어 320px 추가 확인.
- 최종 문구는 3개 언어의 1280px 실제 페이지와 동일한 생성 HTML·스타일을 사용하는 390px 브라우저 프레임에서 추가 확인. 최종 검수 세션의 viewport 변경이 적용되지 않아 프레임으로 문구 줄바꿈을 확인함.
- 가운데 정렬, 세 연도, 배경 사진 로딩, 이전 사진 패널 제거, 가로 넘침 없음, 깨진 이미지 없음 확인.
- 언어 전환과 한국어 히스토리 버튼을 클릭해 기존 연혁으로 연결 확인. 관찰된 콘솔 오류 없음.
- 배경·연혁에는 자동 이동 없음. 제목의 기존 단발성 등장 효과는 reduced-motion에서 실행되지 않음.
- 증거: `output/playwright/home-history/ko-desktop-final.png`, `ko-mobile.png`, `es-mobile.png`, `browser-checks.json`.

이 기록은 로컬 구현 검수이며 공개 배포 완료 기록이 아님.
