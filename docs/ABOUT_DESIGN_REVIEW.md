# 어바웃 디자인 재수정 · 2026-09-11 · about4

2026-09-12 홈·어바웃 공통 구성과 등장 효과 개선은 [템플릿 구성 검토](TEMPLATE_LAYOUT_REVIEW.md)에 기록했다. 아래 내용은 이전 수정 이력이다.

사용자 피드백: 아치·기울어진 로고판이 촌스럽고, 연혁 사진에서 인물이 잘림. 아래 변경으로 이전 about3의 장식 중심 구성을 대체했다.

- Historia de Marca: 아치, 주황색 사진 받침, 사진 확대·이동 효과 제거. 넓은 제목 아래 직사각형 사진과 본문을 정렬하는 편집형 구성. 모바일은 제목 → 사진 → 본문.
- MOKDA: 주황색 전체 배경과 기울어진 도형 제거. 밝은 배경에서 원본 로고와 이름·상징 설명을 여백과 타이포그래피로 구분.
- Nuestra trayectoria: 이미지의 고정 높이, object-fit:cover, scale, translate 제거. 720×1279 원본 비율 그대로 height:auto / object-fit:contain 표시. PC 실측 280×497.375. 연혁 사진은 스크롤 움직임에서도 제외. 낮은 PC 화면에서는 고정 배치 해제.
- 승인된 pageCopy 3개 언어와 연혁 8개 항목, 버튼 수, CTA 목적지 유지.
