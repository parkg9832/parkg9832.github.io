## 구현 전 검토

현재 MOKDA는 브랜드 설명과 연혁이 비슷한 크림색 배경과 좌측 정렬에 반복 배치되어 구간별 역할이 약하다. 신규 작업 중이던 뉴스의 좌측 제목·우측 사진 구성도 최신 가운데 정렬 요청에 맞춰 바꿔야 한다.

개선안은 오렌지 브랜드 도입, 크림색 시작 이야기, 짙은 갈색 브랜드 방향, 밝은 이름 설명, 사진 중심의 주요 연혁 순서다. 제목과 소개는 가운데에 놓고 충분한 너비의 실제 사진을 연결한다. 홈의 제품·음식·현장·소식 흐름은 유지한다. 연혁의 지원사업 8개 기록은 삭제하지 않고 펼침 영역에 보존한다. 주요 장면의 날짜는 확인된 시제품 출시(2026.08)와 Expoalimentaria(2026.09)를 사용한다. 생산 시설 사진에는 임의의 촬영일이나 시설 소유권을 붙이지 않는다.

움직임은 한 번만 짧게 나타나는 사진·제목과 버튼 반응으로 제한한다. 콘텐츠는 애니메이션 없이도 처음부터 표시되고, 모션 감소 설정에서는 움직임을 끈다. 자동 띠, 과장된 스크롤 효과와 페이지 이동을 강제하는 효과는 사용하지 않는다.

## 사진 사용

MOKDA SNS 및 Expoalimentaria 2026 폴더를 연결 도구로 확인했다. 기존에 가져온 대표와 부스 사진(expo-people), 방문객과 소스를 든 사진(expo-visitors), 소스를 든 단체 사진(kpop-group), 현장 사진과 실제 제품 사진을 재사용한다. 도입과 연혁에 같은 사진을 반복하지 않도록 방문객 사진을 연혁에 사용했다. 한국 고추밭·미팅·생산 시설 자료 사진은 기존 승인 자산이다. 현장 기록을 생성형 이미지로 대체할 필요는 없다.

## 구현 후 검토 기록

1차 — 구간과 구성: 한국어 데스크톱에서 오렌지 도입, 크림색 기원, 갈색 음식·방향, 밝은 이름 설명, 사진 중심 연혁을 직접 확인했다. 기존 연혁 8개 항목을 native details 안에 보존했다. 출처가 없는 긴 역사·지속가능성 주장은 추가하지 않았다.

2차 — 데스크톱·태블릿: 세 언어의 브랜드·뉴스 목록·국회방송 상세를 1440/768px에서 확인했다. 모든 공개 제목은 가운데 정렬이며 잘림과 페이지 가로 넘침이 없었다. 뉴스 상세의 980px 영상과 관련 소식 링크를 확인했다.

3차 — 모바일: 브랜드·뉴스 목록·국회방송·KPOP 상세를 390/320px, 세 언어로 확인했다. 2·3차 합계 42개 화면 조합에서 가로 넘침과 공개 제목 잘림이 없었고 카테고리 탭은 0개였다. KPOP 단체사진은 전체 인물이 보인다. 키보드 Enter로 연혁을 열고 닫았으며, 연혁 위치를 유지하는 언어 전환을 확인했다.

4차 — 실제 기능과 비교: 홈 320/1440px의 세 언어를 확인했다. 공개 섹션 제목은 가운데 정렬이고 홈 소식은 3개다. 스크린리더용으로 숨긴 기존 후기 제목은 시각적 넘침 대상에서 제외했다. KOTRA 검색 2건·초기화 6건을 확인했다. 국회방송은 실제 89.93초/258.83초 재생, readyState 4, 오류 없음. 닫은 뒤 플레이어 0개와 버튼 포커스 복귀를 확인했다. 모바일 메뉴에는 모든 소식 링크만 남고 카테고리 링크가 없다.

검토 중 발견한 문제: 홈의 #home-news 직접 링크는 화면 재구성 때문에 상단 다른 구간에 멈췄다. 신규 이동일 때만 load 뒤 정렬하고, 사용자 스크롤·새로고침·뒤로가기에는 개입하지 않도록 수정했다. 실제 도착점은 헤더 아래 80px, 새로고침 전후 스크롤은 4158px로 같았다. 로고의 실제 크기(500×500)와 이미지 대체 설명도 수정했다.

하인즈와 비교한 최종 판단: 큰 사진, 한 구간에 한 이야기, 분명한 제목과 제품으로 이어지는 동선을 적용했다. 하인즈의 빨강·방패 모양·역사·주장을 복제하지 않았다. MOKDA는 오렌지·크림·갈색과 대표의 한국·페루 현장 사진으로 현재의 제품 개발 여정을 설명한다. 하인즈 제품 캐러셀에서 다음 버튼을 눌러 실제 약 332px 가로 이동도 확인했다. MOKDA의 2개 제품에는 불필요한 제품 캐러셀을 추가하지 않았다.
