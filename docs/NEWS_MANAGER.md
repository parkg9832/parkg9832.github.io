# MOKDA 소식 관리

## 시작

프로젝트 폴더에서 `npm run preview:static`을 실행하면 공개 화면 미리보기가 `http://127.0.0.1:4177`에서 열린다. 다른 터미널에서 `npm run manage:news`를 실행하고 `http://127.0.0.1:4178`을 열면 소식을 관리할 수 있다. 현재 작업에서는 두 서버를 실행해 두었다.

관리 화면은 이 컴퓨터에서만 접근하는 로컬 도구다. 저장하면 홈페이지 파일과 3개 언어 미리보기가 갱신된다. 온라인 운영 사이트에 반영하는 배포는 별도로 진행한다.

## 등록과 수정

1. 왼쪽에서 기존 소식을 선택하거나 ‘+ 새 소식’을 누른다. 기존 소식 주소는 유지한다. 새 주소는 영어 소문자·숫자·하이픈으로 입력한다. 예: `new-exhibition`.
2. 분류와 게시일을 입력한다. 행사 날짜는 확인된 경우에만 입력하고, 불명확한 날짜는 비워 둔다. 파일 전송 날짜를 행사 날짜로 사용하지 않는다.
3. 표지 이미지, 선택 영상, 갤러리 이미지를 지정한다. ‘+ 미디어 추가’에서 새 파일을 등록할 수 있다. 갤러리는 이미지 이름을 쉼표로 구분한다.
4. 한국어·Español·English 탭에서 제목·요약·사진 설명·본문을 입력한다. 번역은 자동 생성하지 않는다. 본문은 `## 소제목` 다음 줄에 내용을 쓰며 HTML은 사용하지 않는다. 사진 캡션은 선택이다.
5. 관련 소식과 홈 노출 위치를 선택하고 ‘저장하고 미리보기 갱신’을 누른다. 완료 표시를 확인한 뒤 공개 미리보기에서 결과를 확인한다.

기존 출처 정보는 수정 시 보존된다. 신규 원본 링크와 근거는 `docs/NEWS_MEDIA_REGISTER.md`에도 기록하고 필요하면 `site-news-data.js`의 `sources`에 추가한다. 계약·매출·참여 인원과 확인하지 못한 직함을 추정하여 작성하지 않는다.

## 홈과 소식 목록

- 홈은 대표 소식 1개와 작은 카드 2개를 보여준다. 새 소식을 같은 위치에 지정하면 기존 소식은 홈에서 교체되며 소식 목록에는 남는다. 각 위치는 비워 둘 수 있다.
- ‘홈에 크리에이터 협업 영상 표시’로 협업 영상 영역을 켜거나 끌 수 있다. 기존 5편은 하나의 협업 소식에 묶었으며 영상 카드에는 계정명과 재생 시간만 표시한다. 한 줄 가로 영역에서 좌우로 이동하며, 클릭하면 해당 카드 안에서 바로 재생된다. 좌우 버튼과 자동 이동 일시정지를 제공하며 시청·마우스 진입·키보드 카드 조작 중에는 자동 이동을 멈춘다. 운영체제의 동작 줄이기 설정에서는 자동 이동을 기본으로 끈다.
- 소식 목록은 게시일 최신순이며 한 페이지에 최대 9개를 표시한다. 소식이 늘면 페이지 이동이 자동으로 생긴다. 분류·검색·페이지는 주소에 보존되어 뒤로 가기와 언어 전환에서도 유지된다.
- JavaScript를 사용하지 않는 환경에서도 생성된 모든 소식 카드와 상세 본문을 읽을 수 있다.

## 미디어

JPG·PNG·WebP 사진과 MP4 영상을 파일당 최대 100MB까지 추가할 수 있다. 사진은 가로 최대 1200px/640px WebP 두 가지로 변환한다. MP4는 웹 재생용 H.264/AAC와 faststart로 변환하며 요청할 때만 재생 파일을 불러온다. 영상 변환에는 FFmpeg가 필요하다. 현재 설치된 로컬 도구를 자동 탐색하며 다른 환경에서는 `MOKDA_FFMPEG`에 실행 파일 경로를 지정할 수 있다.

미디어 추가와 소식 저장은 구분된다. 업로드한 미디어를 선택한 뒤 소식을 저장해야 해당 소식에 연결된다. 사용하지 않는 업로드 파일을 자동 삭제하지 않는다. 홈페이지에 공개할 권한이 있는 미디어만 등록한다.

## 백업과 검증

저장 전 데이터 원본을 `output/news-manager/backups/`에 백업한다. 이 폴더는 Git에서 제외되므로 다른 컴퓨터로 옮길 때 필요한 백업을 별도로 보관한다. 동시 수정 시 오래된 화면의 저장을 거절하므로 관리 화면을 새로 열어 최신 데이터를 확인한다. 생성에 실패하면 저장된 원본을 보존하고 오류를 표시한다.

복원이 필요하면 서버를 중지하고 현재 원본도 보관한 뒤 원하는 백업을 검토하여 `site-news-data.js`로 복사하고 `npm run generate:i18n`을 실행한다. 생성된 HTML만 복원하면 다음 생성 때 덮어써진다.

주요 검사는 `npm run test:news`, `npm run test:news-manager`, `npm run test:seo`, `npm run test:integrity`, `npm run test:navigation`, `npm run test:security`다. 관리자 검사는 공개 데이터에 시험 소식을 추가하지 않고 `output/` 안의 별도 작업본에서 등록·수정·3개 언어 생성·업로드를 확인한다.
