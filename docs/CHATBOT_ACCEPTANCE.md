# MOKDA 선택형 상담 운영 규정

적용일: 2026-10-20. 사용자 승인: 선택형 안내를 기본으로 하고 AI는 사용하지 않는다. 이전 자유 대화형 설계보다 이 규정이 우선한다.

1. 홈페이지 우측 하단의 먹랑이 상담창과 승인된 차콜·중립 배경·절제된 오렌지 색상을 유지한다.
2. 문의 목적 → 정보 안내 → 문의 작성의 세 단계로 안내한다. 첫 선택은 제품·개인 구매 / 사업 거래 / 기타 문의다. 처음부터 자유 질문 입력창을 보이지 않는다.
3. FAQ는 공개 제품 정보와 `site-company-knowledge.js`의 확인된 거래 조건으로 답한다. 제품 비교·맵기·활용·보관·원재료·구매와 가격·MOQ·샘플·포장·자료·출고·독점/OEM을 안내한다. 제품 상세와 한국 소비자 구매용 공식 Instagram 링크를 제공한다.
4. 사업 거래에서는 국가·지역, 업종, 관심 제품을 한 화면에서 받는다. 세 정보가 확인되면 기존 `chat_qualified` 이벤트를 유지하되, 즉시 WhatsApp으로 밀어내지 않고 거래 FAQ를 먼저 보여준다. 제품 상세의 사업 CTA는 해당 제품을 미리 선택한다.
5. 추가 확인이 필요한 방문자만 마지막 문의 작성 단계로 이동한다. 일반 문의·협업·제품 문제에는 실제 문의 내용을 받는다. 거래 정보를 확인한 사업자는 추가 내용 없이도 견적·샘플 상담을 준비할 수 있다. 마지막 입력은 질문에 자동으로 답하는 채팅 입력창이 아니다.
6. 선택 정보와 추가 문의를 정해진 양식으로 묶어 먼저 보여준다. WhatsApp 버튼은 이 검토 화면에서만 나타난다. ‘WhatsApp이 열리면 직접 전송’한다고 명시한다. 자동 발송·담당자 접속·실제 문의 저장 성공을 주장하지 않는다. 문의 폼 대체 경로에도 현재 국가·제품·문의 내용을 전달한다.
7. 국가·지역은 `data/countries.json`을 기준으로 검색·선택하고, 목록 밖 지역은 직접 입력한다. 전 세계 선택 범위와 판매 가능 국가는 다른 정보다. 생성 명령 `node scripts/generate-country-data.mjs`는 런타임 목록과 수집 서버의 고정 허용 목록을 맞춘다. 직접 입력한 지역 원문은 문의 초안에만 넣고 분석에는 `Other`로 보낸다.
8. 활성 상담창에서 AI 클라이언트·자유 문장 해석 엔진·챗봇 Turnstile을 불러오지 않는다. 공개 설정은 AI 비활성, 기존 Worker도 `CHAT_AI_ENABLED=false`로 추론을 차단한다. 문의 양식의 봇 검증과 서버 보호는 유지한다. 이전 AI 소스·자격증명·기록은 임의 삭제하지 않는다.
9. 새 상태 저장 키는 `mokdaGuidedHelpV3`다. 네 시간 안의 진행 단계·폼 값·추가 문의를 복구한다. 기존 자유 대화는 접힌 이전 대화로 보존하고, 작성 중인 초안과 제품·국가를 새 흐름으로 옮긴다. 언어 변경 시 진행 정보를 유지하고 안내 언어 변경을 명시한다.
10. 입력값은 문자로만 출력한다. 문의 원문·직접 입력 지역·연락처를 분석에 넣지 않는다. 기존 내부 방문 제외·verification·서버 저장 성공 기준을 유지한다. 국가는 고정 데이터로 검증한다.

검증: `npm run generate:i18n`, `npm run test:help`, `npm run test:funnel`, `npm run test:dashboard`, `npm run test:analytics`, `npm run test:security`, `npm run test:performance`, `npm run test:integrity`, `npm run typecheck`, Worker 테스트. 실제 브라우저에서는 세 언어, 모바일 320/390/430px 및 데스크톱, 국가 검색·직접 입력, 뒤로 가기·초안 복원·언어 변경, 마지막 입력과 WhatsApp 초안을 확인한다. 실제 시험 메시지나 문의 폼은 전송하지 않는다.

국가 코드 출처: [UN M49](https://unstats.un.org/unsd/methodology/m49/overview/), [ISO TW 항목](https://www.iso.org/obp/ui/#iso:code:3166:TW). 한국어·스페인어·영어 표시는 확인한 로케일 이름과 통상 표기를 사용한다. 국가·지역 목록은 영업 지역이나 인증·수출 가능성의 보증이 아니다.
