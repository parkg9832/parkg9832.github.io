# 출시 응원 페이지 제거 · 2026-09-12

사용자 요청에 따라 응원 페이지 자체를 사이트에서 제외했다.

- 홈 응원 수·메시지 영역 및 응원 데이터 조회 코드 제거.
- 공통 헤더/푸터 응원 링크와 제품별 출시 응원 버튼 제거. B2B 문의는 유지.
- 다국어 생성 대상과 사이트맵에서 support.html 제외: 현재 활성 페이지는 5개 × 3언어.
- /support.html은 스페인어 홈, /es|en|ko/support.html은 해당 언어 홈으로 즉시 이동하는 noindex 문서로 생성한다. 기존 주소를 열어도 응원 폼이 실행되지 않는다.
- 기존 응원 데이터, 서버 Apps Script, 보관용 스크립트는 삭제하지 않았다. 원본 페이지는 작업 폴더 tmp/design-audit에 백업했다.
- 다국어 생성, 분석 회귀 14개, 타입 검사 통과. 실제 브라우저에서 기존 ES 주소의 홈 이동, 제품 버튼 제거와 응원 링크 0개 확인.
- 이전 날짜 수정은 현재 활성 사이트에서 사용되지 않는다. 공개 배포·푸시 없음.
