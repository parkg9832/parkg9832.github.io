# MOKDA WhatsApp 상담 운영

홈페이지 반영일: 2026-10-11. 플랫폼 자료 확인일: 2026-10-10. 현재 범위는 홈페이지 채팅 상담과 담당자 문의 연결이며, WhatsApp 계정 설정·API 자동화는 별도 작업이다.

## 홈페이지 채팅 상담

- 모든 공개 페이지의 우측 하단 원형 버튼에서 대화창을 연다. 짧은 인사, 4개 상담 주제, 소스 추천·구매처·유통 상담의 빠른 질문을 제공한다. 직접 질문을 입력할 수도 있다.
- 공개된 답변 14개를 한국어·스페인어·영어로 제공한다. 직접 입력은 명확한 질문만 준비된 답변에 연결하며, 불명확하거나 여러 요청이 섞인 질문은 담당자 문의로 안내한다. 생성형 AI나 실시간 상담원 연결이 활성화된 것으로 표시하지 않는다.
- 짧은 인사와 감사에는 별도로 응답한다. 질문이 붙은 문장은 기존 질문 연결 규칙을 사용하며, 인사·감사 때문에 담당자에게 전달할 마지막 문의 내용이 바뀌지 않도록 한다.
- 대화창은 페이지를 차단하지 않는다. 닫았다 다시 열면 현재 페이지의 대화를 유지하고, 새 대화를 누르면 초기화한다. 말풍선은 최근 25개, 입력은 500자로 제한한다.
- 대화를 서버로 전송하거나 저장하지 않는다. 담당자 문의 링크를 직접 누른 경우에만 마지막 질문을 브라우저의 sessionStorage로 문의 양식에 옮기며, 양식에서 읽은 뒤 바로 지운다. 문의 제출은 방문자가 별도로 진행한다.
- 디자인 참고: [채널톡의 챗봇 사례 6개](https://channel.io/kr/blog/articles/best-chatbot-case-6-371158df). 말풍선 안에서 상담을 시작하는 방식, 목적에 따른 짧은 질문, 브랜드의 인사와 선택 버튼을 참고했다. 이 글은 2020년 사례이며 제품의 현재 명칭이나 운영 요건을 판단하는 자료로 사용하지 않는다.

## 업무 번호와 홈페이지 연결

- 업무용 서브폰과 공식 업무 번호에 WhatsApp Business를 등록하는 구성을 권장한다. 개인 연락과 고객 상담을 구분하고, 업무 시간·제품 카탈로그·담당자 인계를 관리하기 쉽다.
- 홈페이지에서는 채팅창 열기 → 주제 선택 → 질문 선택의 최대 3번 행동으로 준비된 답변을 보여준다. 빠른 질문이나 직접 입력은 주제 선택 없이 답변을 제공한다. 답변에서 담당자 문의로 연결할 수 있다.
- 대표님이 2026-10-11 제공한 공식 WhatsApp Business 번호를 `site-contact-config.js`의 `window.MOKDA_CONTACT.whatsappNumber`에 국가번호를 포함한 숫자로 등록했다. 홈페이지 상담 버튼은 이 번호의 WhatsApp 대화를 열고, 현재 언어의 인사와 마지막 질문을 전송 전 초안으로 전달한다. 메시지를 실제로 보내는 행동은 고객이 WhatsApp에서 진행한다.
- 번호가 비어 있거나 형식이 잘못되면 기존 문의 페이지로 연결한다. 연결만 제공하는 기능을 WhatsApp AI 자동응답이 활성화된 것으로 안내하지 않는다. 수신·Business Agent 계정 설정은 홈페이지의 링크 검증과 별도로 확인한다.

## Business 앱에서 사용할 기능

- 인사 메시지: 처음 문의하거나 14일 동안 대화가 없었던 고객에게 설정 문구를 자동 전송한다.
- 부재 메시지: 지정한 시간·대상에 맞춰 자동 전송한다. 영업시간 밖 설정은 사업자 프로필의 영업시간을 먼저 등록해야 한다.
- 빠른 답장: 담당자가 저장 문구를 선택하고 직접 전송한다. 질문을 이해해 답하는 AI 자동응답과 다르다.
- 인사·부재 자동 전송에는 기기의 인터넷 연결이 필요하다. Meta Business Agent를 연결하면 기본 인사 메시지는 자동 비활성화되므로 설정 후 실제 동작을 다시 확인한다.

참고: [인사 메시지](https://faq.whatsapp.com/501866148528310/?cms_platform=android), [부재 메시지](https://faq.whatsapp.com/2565868990219715/?cms_platform=android), [빠른 답장](https://faq.whatsapp.com/1791149784551042/?cms_platform=iphone&locale=en_US).

## Meta Business Agent 사용 가능 여부와 비용

- 고객에게 직접 답하는 기능은 Meta Business Agent다. 일반 Meta AI나 사업 운영 도우미와 구분한다.
- 제공 대상은 일부 국가·언어·계정이며, Business 앱의 `Tools → AI agent` 메뉴에서 확인한다. 메뉴가 없으면 현재 해당 계정에는 제공되지 않은 것이다. 언어는 사업자 전화번호에 따라 결정된다. 한국·페루·한국어 지원을 일괄 보장하지 않는다.
- 앱에서는 매월 포함된 무료 한도까지 사용할 수 있고, 추가 응답은 Meta One 구독으로 제공한다. 한도·가격·혜택은 지역과 계정에 따라 다르므로 앱의 가입 화면에서 확인한다. 앱 구독은 WhatsApp Business Platform(API) 요금과 별개다.
- Agent를 켜기 전에 답변과 담당자 전환을 시험한다. 판매 국가·재고·가격·최소 주문량처럼 확정되지 않은 정보는 답변하도록 학습시키지 않는다.

참고: [Agent 설정과 제공 조건](https://faq.whatsapp.com/1153795669452207/?cms_platform=web), [Business Agent 제품 안내](https://whatsappbusiness.com/products/business-app-ai-agent/), [Meta One 무료 한도와 구독](https://whatsappbusiness.com/products/business-app-meta-one/).

## 향후 API 자동화

- 실제 구현에는 공식 Business Platform 계정·등록된 업무 번호, API 접근 권한, 수신 webhook과 응답 서버, 서버에 보관하는 인증 정보, 확정된 답변 자료와 담당자 전환 경로가 필요하다. 현재는 공개 상담 번호와 대화 링크만 등록했으며 API 토큰·계정 자동응답 설정은 추가하지 않는다.
- 고객이 보낸 문의에만 응답하고, 담당자를 요청하거나 답변 근거가 없으면 자동응답을 멈추고 담당자에게 넘긴다. 문의에 필요한 정보만 다루며 확정되지 않은 견적·판매 가능 여부를 만들지 않는다.
- 일반 응답은 고객의 마지막 메시지로부터 24시간 안에 보낼 수 있다. 그 밖의 발송에는 승인된 메시지 템플릿 등 별도 조건이 필요하다. 현재 범위에 선제 홍보 발송은 포함하지 않는다.
- 2026-10-01부터 공식 FAQ는 서비스 메시지를 번호당 매월 첫 1,000개 무료, 1,001개부터 메시지별 과금한다고 명시한다. 24시간 응답 가능 구간을 무제한 무료 구간으로 설명하지 않는다.
- 공식 가격 소개 페이지에는 여전히 서비스 메시지 무료 문구가 남아 있다. 날짜가 명시된 FAQ 변경사항을 우선하고, 연결 전에 현행 요금표와 계정의 결제 조건을 확인한다.
- Platform의 Meta Business Agent는 AI 사용과 메시지 전달을 합친 토큰 과금이다. 외부 AI를 쓰는 경우에는 Meta 메시지 비용, 모델 이용료, 응답 서버와 선택한 연결 업체의 비용을 나눠 확인한다. 전체 무료라고 보장하지 않는다.

참고: [공식 FAQ의 날짜별 과금 안내](https://whatsappbusiness.com/resources/faq/), [가격 소개 페이지](https://whatsappbusiness.com/products/platform-pricing/), [Business 메시지 정책](https://whatsappbusiness.com/policy/), [API 시작 문서](https://developers.facebook.com/documentation/business-messaging/whatsapp/get-started). Developer 문서는 확인 시 접근 제한이 있어, 계정 연결 시 최신 기술 요건과 요금표를 다시 읽는다.

## 답변 자료 갱신

- 홈페이지 상담 질문·답변은 `site-help-data.js`, 직접 입력의 질문 연결 규칙은 `site-chat-intents.js`에서 관리한다. FAQ·제품 설명·판매 상태가 바뀌면 해당 콘텐츠 원본과 이 파일의 한국어·스페인어·영어 답변을 함께 갱신·검수한다. 생성된 언어별 HTML만 직접 수정하지 않는다. 변경 후 `npm run test:help`로 답변 연결과 대화 동작을 검증한다.
- Meta Business Agent에는 확인된 홈페이지·카탈로그·FAQ와 담당자 전환 기준을 제공하고, Business 앱 `Tools → AI agent`에서 지식과 지침을 갱신한 뒤 고객 역할로 시험한다. 홈페이지 배포가 Agent의 학습자료까지 즉시 갱신한다고 가정하지 않는다.
- 문의 번호 갱신은 `site-contact-config.js`에서 관리한다. API 비밀키·토큰·고객 대화는 공개 홈페이지나 저장소에 넣지 않는다.
