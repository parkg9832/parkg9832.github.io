# MOKDA 소식 제작 및 검증 기록

2026-10-07. 승인한 시안을 기존 정적 홈페이지에 구현하고, 후속 요청에 따라 홈 대표 활동과 누적 소식 목록을 분리했다. 커밋·푸시·운영 배포는 하지 않았다.

## 구현 결과

- 홈에 박람회 대표 영역, KPOP STYLE·국회방송 카드 2개와 소식 목록 연결을 추가했다. 대표 활동의 노출 위치는 관리 화면에서 변경한다.
- 공통 상단 메뉴와 하단 메뉴에 MOKDA 소식을 연결했다. 태블릿 메뉴는 4개 그룹을 2열로 표시한다.
- 소식 목록은 같은 크기의 카드로 누적 게시물을 보여준다. 전체/소식·미디어/행사/콜라보 필터, 검색, 한 페이지당 9개와 페이지 이동을 제공한다. 주소에 분류·검색·페이지를 보존하며 뒤로 가기와 언어 전환도 지원한다.
- 반복적인 ‘처음 만나는 Salsa Coreana’, ‘식탁에서 만난 Salsa Coreana’ 등의 작은 소식 제목·설명을 제거했다. 크리에이터 협업은 상세 페이지 하나에 묶고 영상 카드에는 계정명과 재생 시간만 표시한다. 홈에도 협업 영상 영역을 제공한다.
- 기존 주황·크림·브라운 구도와 실제 사진을 유지하며 제목 크기, 카드 이미지 비율, 날짜·분류 정렬, 요약 길이, 구분선·화살표·검색·탭·모바일 여백을 정리했다.
- 박람회, KPOP STYLE, KOTRA 리마무역관, 페루 국회방송, 크리에이터 협업의 상세 페이지 5개를 제공한다. 관련 소식, 사진 설명, 출처 및 문의 연결을 포함한다.
- 한국어·스페인어·영어로 소식 목록과 상세 페이지 18개를 생성했다. 전체 사이트는 검색 가능한 지역화 문서 39개다.
- 크리에이터 영상 5편과 현장 영상 3편을 실제 미디어로 연결했다. 사진·썸네일은 26개 WebP 변형을 사용한다.
- 영상은 클릭할 때만 불러온다. 닫으면 재생을 멈추고 파일 주소를 해제하며 포커스를 재생 버튼으로 복원한다. 모바일 인라인 재생과 직접 파일 열기 대안을 제공한다.
- 협업 문의 버튼은 `contact.html?purpose=collaboration`으로 이동하고 문의 유형을 자동 선택한다. 실제 문의 전송은 검증 과정에서 실행하지 않았다.
- 공유 링크 복사, canonical·hreflang·Article 구조화 데이터 및 sitemap을 연결했다. 원본은 `site-news-data.js`에서 관리한다.
- 로컬 관리 화면에서 새 소식 등록·수정, 3개 언어 입력, 홈 노출 교체, 사진·MP4 업로드 및 자동 백업을 제공한다. 저장 시 상세·언어별 페이지와 sitemap을 자동 생성한다. `npm run manage:news`로 시작하며 사용법은 `NEWS_MANAGER.md`에 기록했다.

실제 Chromium 브라우저에서 3개 언어 × 1440px 데스크톱/390px 모바일 × 홈·목록·상세 5개, 총 42개 화면을 확인했다. 실제 WebP 로딩을 확인한 후 스크린샷을 저장했고 모든 조합에서 스크립트 오류와 로컬 파일 HTTP 오류가 없었다. 추가로 320·768·1024px에서 소식 목록의 가로 넘침이 없음을 확인했다.

최종 영상 8편에서 메타데이터·재생 시간 증가·구간 이동·Escape 닫기·포커스 복원을 확인했다. 모바일에서도 크리에이터 영상 재생을 확인했다. MP4 파일은 H.264/yuv420p이며 원본과 재생 길이 차이가 0.25초 이내다. 방송 영상은 약 40MiB, 크리에이터 영상은 약 6.6~17.4MiB다. 목록을 열 때 MP4를 요청하지 않는다.

추가 사용자 흐름도 확인했다.

- 필터 변경 후 뒤로 가기에서 이전 필터 복원.
- 실제 Chromium의 시험 데이터 25개에서 9/9/7 페이지 이동, 분류 변경 시 첫 페이지 복귀, 검색·초기화 확인. 시험 게시물은 공개 데이터에 저장하지 않았다.
- 스페인어 행사 필터에서 한국어 전환 후 필터 및 기존 캠페인 쿼리 유지.

- 문의 페이지 진입 후 ‘MOKDA 협업’ 자동 선택.
- 모바일 메뉴의 콜라보 링크로 진입 후 해당 섹션 표시.
- JavaScript를 끈 상태에서도 스페인어 소식 제목과 카드 본문 표시.
- 로컬 검증 중 Google Analytics·GTM·Apps Script 분석 요청 없음.
- 실제 관리 화면의 3개 언어 탭·모바일 레이아웃·새 글 모드와 기존 소식 저장 후 자동 생성 완료 확인.

## 후속 개선: 카드 내 재생과 가로 이동

영상 팝업을 제거하고 홈·크리에이터 상세·현장 영상 모두 썸네일 자리에서 직접 재생하도록 변경했다. 카드의 높이를 유지하며 한 번에 하나의 플레이어만 사용한다. 다른 영상을 열면 이전 재생을 중지하고 파일 주소를 해제한다. 닫기 버튼과 Escape는 썸네일로 복귀하며 키보드 포커스를 복원한다. 로딩 오류 시 직접 파일 열기 링크를 표시한다.

크리에이터는 모든 화면 크기에서 한 줄 가로 영역으로 표시한다. 자동으로 천천히 좌우 이동하며 화살표·일시정지·터치 스크롤·키보드 조작을 제공한다. 마우스 진입, 카드 키보드 포커스, 열린 플레이어, 수동 이동 직후에는 자동 이동을 멈춘다. 화면 밖과 비활성 탭에서는 이동을 중지하며 동작 줄이기 설정에서는 기본으로 자동 이동을 끈다. 복제 카드나 추가 동영상 다운로드는 사용하지 않는다.

실제 Chromium에서 3개 언어 × 1440px/390px 홈, 크리에이터 상세 영상 5편, 현장 영상 3편의 메타데이터·재생·구간 이동·닫기와 높이 유지, 단일 플레이어, 자동 이동·마우스/시청 일시정지·수동 버튼을 검증했다. 390px 한국어 협업 영역 높이는 약 510px이며 모든 영상 카드가 같은 줄에 있다. 320px에서도 페이지 가로 넘침이 없다. 스크립트·로컬 파일 오류와 로컬 분석 전송은 없었다.

`npm run generate:i18n`, `test:news`, `test:analytics`, `typecheck`, `test:integrity`, `test:security`, `test:navigation`이 통과했다. 새 동작의 스크린샷과 결과는 `output/playwright/news-inline/`의 `result.json`, `ko-home-1440.png`, `ko-home-390.png`, `inline-1440.png`, `inline-390.png`에 보관했다. 위 `news-v2` 기록은 이 변경 직전의 화면이다.

## 후속 피드백: 중복 영역·모션 제거와 KPOP 사진 교체

기존 체험단 후기 영역을 유지하고 홈 소식 아래의 별도 크리에이터 블록은 `homeCreators:false`로 표시하지 않는다. 콜라보 상세의 영상 5편과 카드 내 재생은 유지한다. 신규 하단 모션 전용 CSS/JS 연결을 홈 원본에서 제거해 주황색 이동 문구 띠, 사진 스크롤 이동, 제목·카드 등장 및 FAQ 강조를 해제했다.

KPOP STYLE의 홈·목록·상세 표지는 소스를 들고 함께 선 단체사진으로 교체했다. 사용자가 바탕화면에 제공한 관객석 배경 사진을 상세 갤러리에 추가했다. 원본을 보존하며 빈 하늘만 잘라 1200px/640px WebP로 최적화했다. 원본 매핑은 `NEWS_MEDIA_REGISTER.md`에 기록했다.

한국어·스페인어·영어 × 1440px/390px 실제 Chromium에서 중복 블록·신규 모션 해제, 기존 후기 유지, 단체사진·관객석 사진 로딩, KPOP 영상과 크리에이터 영상의 페이지 내 실제 재생·닫기, 가로 넘침과 콘솔/응답 오류 및 로컬 분석 차단을 확인했다. 6개 화면 조합이 통과했고 오류는 0개다. 증거는 `output/playwright/news-feedback/result.json`과 언어별 `*-home-*`, `*-kpop-*`, `*-crowd-*` 스크린샷이다.

`generate:i18n`, `test:news`, `test:analytics`(14개), `typecheck`, `test:seo`(39개 문서), `test:integrity`(600개 내부 링크·82개 참조 에셋), Git 공백 검사가 통과했다. 운영 배포는 하지 않았다.
