## 교정한 설정

사용자가 이번 상담창 변경과 함께 아래 두 문제를 수정하도록 승인했다. 생성 원본·루트 HTML·SEO 검사 코드를 수정했고, 48개 페이지 재생성과 변경 후 SEO·상담·내부 링크 검사를 통과했다. 공개 배포 결과는 별도의 운영 검증 근거로 확인한다.

### 1. Google이 지원하지 않는 스페인어 hreflang

점검 당시 모든 페이지의 스페인어 alternate에 `hreflang="es-419"`가 들어 있었다. Google 공식 문서의 2026-09-21 갱신본은 `es-419`가 Google hreflang 지원 코드에 포함되지 않는다고 명시한다. HTML `lang="es-419"`, JSON-LD `inLanguage="es-419"`, LATAM 스페인어 문구는 그대로 유지하고, 검색 alternate만 `es`로 지정하면 스페인어 사용자에게 같은 페이지를 안내할 수 있다. 국가별로 서로 다른 내용이 없으므로 같은 URL에 여러 국가 코드를 추가할 필요는 없다.

승인받은 수정 범위:

```diff
// scripts/generate-localized-pages.mjs
- ES: { directory: 'es', html: 'es-419', hreflang: 'es-419', og: 'es_419' },
+ ES: { directory: 'es', html: 'es-419', hreflang: 'es', og: 'es_419' },
```

생성의 원본인 루트 HTML의 alternate 태그도 `es`로 맞췄다. 생성된 `/es`, `/en`, `/ko` 파일만 직접 고치지 않는다. SEO 회귀 검사·운영 검사는 HTML 언어와 Google hreflang 값을 각각 검사하도록 바꿨다. 48개 페이지를 재생성하고 변경 후 검사를 통과했다.

### 2. 제품 페이지의 미정의 구조화 데이터 타입

점검 당시 K-PEÑO와 Para Carnes의 JSON-LD 페이지 타입은 `ProductPage`였다. Schema.org의 공식 최신 JSON-LD 정의를 HTTP 200으로 조회해 1,016개 클래스를 검사한 결과, `ProductPage`는 없고 `WebPage`와 `Product`는 존재한다. 이 문제는 제품 2개 × 언어 3개, 총 6개 페이지에 해당한다.

가장 작은 수정은 페이지 자체의 타입을 표준 `WebPage`로 바꾸는 것이다. 실제로 공개하지 않은 가격·재고·평점·상품 판매 조건을 검색용으로 만들어 넣지 않는다. 이 수정은 일반 웹페이지 메타데이터 오류의 교정이며, 쇼핑·상품 리치 결과 노출을 보장하는 작업이 아니다.

```diff
// scripts/generate-localized-pages.mjs — 두 제품 페이지 설정
- type: 'ProductPage',
+ type: 'WebPage',
```

원본의 두 제품 페이지 설정을 `WebPage`로 바꿨고, 검사에 제품 페이지의 표준 타입과 실제 콘텐츠 언어 확인을 추가했다. UI와 제품 본문은 바꾸지 않는다.

### 3. 사이트맵 수정일 관리

점검 당시 모든 URL의 `<lastmod>`가 `2026-10-11`로 고정되어 있었다. Google은 중요한 본문·구조화 데이터·링크 변경에 맞는 정확한 날짜를 권고한다. 이번에 구조화 데이터 타입을 교정하는 두 제품 상세에 페이지별 `lastModified: '2026-10-13'`을 추가했다. 재생성 후 제품 2개 × 언어 3개, 총 6개 URL에만 새 날짜가 들어가며 나머지 42개 URL은 기존 `2026-10-11`을 유지한다. 검사에서도 이 범위를 확인한다. 상담창 색·인사 지연을 이유로 모든 기사와 제품의 날짜를 일괄 갱신하지 않는다.

### 실제 Google 검색 화면

2026-10-13 09:21 KST에 로그인된 Chrome의 한국어 Google 검색 화면에서 확인했다. 결과 근거는 공개 배포하지 않는 `output/seo/google-public-search.json`에 보관한다.

Google에 전혀 노출되지 않는 상태는 아니다. 다만 위 결과만으로 브랜드 일반 검색의 홈페이지 노출이 충분하다고 평가하거나, 사이트의 전체 색인 수·최근 노출·클릭·CTR·평균 순위를 계산할 수는 없다. 단순 `site:` 결과에서 페이지가 빠져 있다는 이유만으로 미색인으로 단정하지 않는다. Google은 `site:` 검색의 결과가 완전한 색인 목록이 아니라고 설명한다.
