## 사실과 편집 원칙

- 박람회 참여, 바이어 미팅, 국회의장·농업부 장관의 부스 방문, KOTRA 미팅, KPOP STYLE 무대인사·추첨 증정은 사용자가 제공한 활동 기록을 바탕으로 작성했다. 계약·매출·바이어 수·방문객 수를 추정하지 않았다.
- Expoalimentaria 행사일은 2026-09-23~25, 게시일은 2026-10-07로 구분했다. KOTRA 미팅과 KPOP STYLE의 정확한 행사일은 자료에서 확인하지 못했으므로 기재하지 않았다. WhatsApp 파일의 날짜를 행사일로 사용하지 않았다.
- [페루 국회 공식 기사](https://comunicaciones.congreso.gob.pe/noticias/presidente-del-congreso-reafirma-su-compromiso-con-los-agricultores-en-inauguracion-de-expoalimentaria-2026/)는 Miguel Ángel Torres Morales를 국회의장으로 소개한다. 홈페이지에 미확인 ‘페루 부통령’ 직함을 넣지 않았다. 현장 부스 방문에 대한 직접 자료는 사용자의 기록과 제공 영상이다.
- KOTRA 미팅 사진을 식별하지 못했다. KOTRA 소식의 표지에는 MOKDA 제품 소개 테이블을 사용하고 실제 내용에 맞는 대체 텍스트를 달았다. 이를 미팅 현장 사진으로 설명하지 않았다.
- KPOP STYLE 상세에는 종료된 추첨 증정 행사라는 내용을 명시했다.
- 방송 출처를 상세 페이지에 연결하고 크리에이터 계정 이름을 각 영상에 표시했다.

## 소식 업데이트

2026-10-07 추가: 사용자가 제공한 [KOTRA 해외시장뉴스 원문](https://dream.kotra.or.kr/kotranews/cms/news/actionKotraBoardDetail.do?SITE_NO=3&MENU_ID=110&CONTENTS_NO=1&bbsGbn=245&bbsSn=245&pNttSn=244542)을 실제 브라우저에서 확인했다. 리마무역관 지정주 작성, 2026-10-06 발행의 Expoalimentaria 2026 참관기에 MOKDA와 박겸 대표 인터뷰가 실려 있다. 별도 `kotra-interview` 소식은 한국어·스페인어·영어의 짧은 자체 소개와 원문 링크로 구성했다. 사이트 게시일(10월 7일)과 기사 발행일(10월 6일)을 구분하고 기존 리마무역관 미팅 기록은 유지했다. KOTRA의 기사 사진을 가져오지 않고 MOKDA 원본 사진을 사용했다.

1. `npm run manage:news`로 로컬 관리 화면을 연다. 사용 방법은 [NEWS_MANAGER.md](NEWS_MANAGER.md)를 참고한다.
2. 한국어·스페인어·영어 제목, 요약, 본문, 이미지 대체 텍스트를 입력한다. 게시일과 확인한 행사일을 구분한다. 사진·MP4는 관리 화면에서 추가할 수 있으며 원본 매핑과 출처는 이 문서에도 기록한다.
3. 저장하면 `site-news-data.js`의 백업을 만들고 상세 페이지·3개 언어 페이지·sitemap을 자동 생성한다. 생성 HTML을 직접 편집하지 않는다.
4. 새 `news-소식주소.html` 경로의 언어 전환과 검사 대상 목록은 자동 반영된다. 현재 카테고리는 소식·미디어/행사/콜라보이며 카테고리 종류를 늘릴 때에는 메뉴·렌더러·검사를 함께 수정한다.
5. `npm run test:news`, `npm run test:news-manager` 및 SEO·무결성·보안·내비게이션 검사와 실제 모바일/데스크톱 화면을 확인한다. 저장은 로컬 파일 갱신이며 운영 배포는 별도다.

Git 커밋, 원격 푸시 및 운영 배포는 이 제작 작업에 포함하지 않았다.

## 최종 영상 미리보기 정리

2026-10-07 배포 전 검수에서 상세 영상 버튼을 실제 영상 프레임으로 교체했다. `expo-video`는 `expo-visit.mp4`의 2초 프레임(3:4 세로), `kpop-video`는 `kpop-event.mp4`의 24초 프레임, `congreso-video`는 `congreso-broadcast.mp4`의 10초 프레임(16:9)이다. 각 파일에 1200px·640px WebP 변형을 제공한다. 국회방송 상세 첫 이미지가 영상 버튼이며, 같은 영상을 하단에 반복하지 않는다. 홈·목록은 기존 방송 표지를 유지한다.
