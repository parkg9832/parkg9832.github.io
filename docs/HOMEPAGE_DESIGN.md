# MOKDA 홈페이지 디자인 · 2026-09-11 스크롤 중심 구성

## 디자인 반영

검수한 본문을 유지하면서 제품, 음식, 브랜드의 실제 활동과 추천사를 서로 다른 크기와 배치로 구성했다. 오렌지·브라운·크림을 이어 쓰고 첫 화면과 제품명은 크게, 일반 섹션 제목은 같은 크기 체계로 정리했다.

순서: 첫 화면 → 제품 → 음식 페어링 → 원료·생산 이야기 → 전문가 추천사 → 기관 → 출시 응원 → FAQ → 문의 → SNS·푸터.

- 한국어는 Noto Sans KR, 영문·스페인어 주요 제목은 Archivo Black을 사용한다. 일반 제목은 32~52px/행간 1.15/자간 -0.025em, 본문 기본 16px/1.7, 보조 라벨 12px/1.5다. 대표 제목과 제품명은 역할에 맞춰 크게 설정했다.
- 제품 사진은 조명과 구도를 맞춘 개별 AI 스튜디오 컷이다. 데스크톱 두 종 병렬, 모바일 두 종 세로 배치다. Ganjang의 기존 리뉴얼 안내는 별도 행으로 유지한다.
- 음식 페어링은 기존 제목·소개를 사용하고 세 가지 음식 사진과 용도를 함께 보여준다. 페어링 탭·중복 상세 링크·장식 배지를 제거했다.
- 추천사는 기존 제목과 전문을 유지한다. 넓은 화면에서는 두 건을 나란히, 모바일에서는 세로로 전문을 보여준다. 자동 넘김과 조작 버튼을 제거했다.
- FAQ는 넓은 화면에서 제목과 질문을 좌우로 배치하고 세 답변을 항상 펼쳐 둔다. 문의는 큰 제목과 원형 버튼으로 마무리한다. 모바일은 세로로 이어진다.
- 추천사 이력의 흐린 글씨와 FAQ 번호의 대비를 높였다. SNS 제목은 하단 정보에 맞는 크기로 낮췄다.
- 중복 출시 안내 띠를 제거했다. 응원 영역의 버튼은 기존 문구 응원하기 / Quiero apoyar / Support the launch를 사용하고 입력 폼에 연결했다.
- 스크롤 후 모바일 메뉴가 높이 0으로 계산되는 문제를 실제 화면에서 발견해 수정했다. 메뉴는 화면 높이에서 상단 바 80px를 제외한 높이로 열린다.
- 제품컷 교체 중 남은 SVG 좌표 참조와 삭제된 페어링 문단 참조를 제거해 화면 초기화 오류를 해결했다.

## 실제 후기 추가

실제 별점·후기가 아직 없다는 사용자 확인에 따라 site-reviews-data.js의 MOKDA_TRIAL_REVIEWS는 빈 배열이다. 일반 홈페이지에는 별점·후기 영역이 표시되지 않는다.

수집 후 공개 동의된 자료만 추가한다. 필수 필드는 published, name, quote, source이며 title/product/rating/photo는 선택이다. quote와 title은 문자열 또는 KR/ES/EN 객체다. rating은 실제 수집한 1~5 정수만 허용하고 미수집 시 생략한다.

이 파일은 공개 정적 자산이다. 연락처·동의서·비공개 원문은 넣지 않는다. published:false도 파일 자체를 비공개로 만들지 않는다. 로컬에서만 ?review_preview=1로 명확히 표시된 예시 구성을 볼 수 있다.
