## 공개 파일과 구도

`assets/images/hero/studio-{01|05|09}-{desktop|mobile}-20261019.webp`를 사용한다. 데스크톱은 1000×1500, 모바일은 720×1280이며 WebP 품질 85다. 원본은 EXIF 방향을 바로잡은 4000×6000 사진이다. 데스크톱은 원본 전체 비율로 축소하고 모바일은 중앙 3375×6000 구도를 사용한다. 생성형 편집·인물 변형·사진 합성은 하지 않았다. 공개 파일의 메타데이터는 제거한다. 원본·후보 목록은 비공개 제작 폴더에 보관한다.

1024px 이상에서는 오른쪽에 세로 사진 전체를 표시하고 왼쪽 읽기 영역 안에 기존 제목·설명·CTA를 가운데 정렬한다. 사진 왼쪽 가장자리는 브라운 배경으로 자연스럽게 연결한다. 1024px 미만은 사진이 화면을 채우며, 문구를 아래쪽에 배치하고 하단 그라데이션으로 대비를 확보한다. 글꼴·제목·설명·CTA 문구와 사진 전환 방식은 유지한다.

## 보관 자산

히어로에서 제외한 `meeting`의 WebP 두 파일은 삭제하지 않고 보관한다. 원본은 [20260923_102003.jpg](https://drive.google.com/file/d/1ZhXAWakWr6anuzhLFa4rH6SwwkKG78ZQ/view), 기존 보관 경로는 `output/media-source/founder-next-0.jpg`이며 EXIF 회전 후 2252×4000이다. 뉴스의 `expo-people.webp`와 동일한 원본이다. 제작 크롭은 데스크톱 `(0, 1100, 2252, 2367)`, 모바일 `(0, 0, 2252, 4000)`으로 기록한다.

## 전환과 로딩

- 첫 사진은 HTML의 실제 이미지로 즉시 표시한다. JavaScript가 없어도 사진과 제품 링크를 이용할 수 있다.
- 4.5초 유지한 뒤 다음 사진이 로드·디코딩되면 800ms 동안 투명도로 전환한다. 확대·이동 효과는 없다.
- 다음 사진 하나만 순서대로 불러온다. 화면 밖·백그라운드·페이지 이탈에서는 타이머와 대기 중 전환을 취소한다.
- 별도의 재생·일시정지 버튼을 표시하지 않는다. 모션 줄이기·데이터 절약 설정에서는 첫 사진만 표시한다.
- 사진을 불러오지 못하면 현재 사진과 기존 문구·제품 링크를 유지한다.
- 공개 페이지는 `home-hero-photos.js`를 사용한다. 이전 영상 파일·컨트롤러·검사 파일은 제작 이력으로 남기며 홈페이지에서는 참조하지 않는다.
