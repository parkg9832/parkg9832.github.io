# 홈페이지 문구 검수 기록

검수일: 2026-10-19

## 범위

- 사이트맵의 공개 페이지 48개: 한국어·스페인어·영어 각 16개.
- 헤더·푸터, 제품·뉴스·FAQ, 문의 폼의 라벨·오류·안내, 챗봇과 회사 안내 원본.
- 스페인어 제품 상세 이미지 18장. 명백한 철자 오류는 발견하지 못해 원본을 유지했다.
- 과거 고객 대화, 외부 기사 원제목, 실제 후기·인용, 제품 수치·사업 날짜는 교정 대상으로 덮어쓰지 않았다.

## 반영

| 구분 | 교정 예 |
|---|---|
| 상담 역할 | Mascota de MOKDA → Asistente de MOKDA, 한국어·영어도 상담 도우미 의미로 통일 |
| 한국어 조사 | 어떤 제품이 관심 있으세요? → 어떤 제품에 관심 있으세요? |
| 표기·띄어쓰기 | 할라피뇨, 엠파나다, 1억 원, 최소 주문 수량, 더 보기 |
| 제품 정보 | 제조일부터 12개월인 항목의 라벨을 보관 기간 → 소비기한으로 정정 |
| 자연스러운 번역 | 첫 번째 표현 → 첫 번째 소스 라인, Interested product → Product of interest |
| 문의 안내 | 이메일 주소 또는 WhatsApp 번호를 남기라는 뜻을 분명히 전달 |
| 문법·병렬 | minimum order quantities(MOQ), distributors / retailers / HORECA businesses |
| 첫 화면 현지화 | 제품·뉴스 등의 기본 메뉴가 JavaScript 실행 전에도 해당 페이지 언어로 표시되도록 생성 단계 보완 |
| 답변 일관성 | 공개 제품 설명의 중간·순한 매운맛과 상담 문구·AI 지침을 일치시킴. 수치나 무매운맛 보장은 추가하지 않음 |
| 기존 세션 | 인사말만 남은 예전 세션은 새 문구로 갱신하고, 진행한 대화·입력 초안은 보존 |

## 언어 근거

스페인어 mascota는 반려동물 외에 대표 캐릭터에도 쓰인다. 단어 자체를 오역으로 분류하지 않고, 상담창에서 역할을 더 쉽게 이해하도록 asistente를 선택했다.

- [RAE: mascota](https://dle.rae.es/mascota)
- [FIFA 스페인어 공식 캐릭터 용례](https://www.fifa.com/es/tournaments/mens/worldcup/canadamexicousa2026/mascots)

## 확인

48개 생성 페이지의 문자 깨짐과 기본 메뉴 언어를 검사했다. 세 언어 상담창을 데스크톱·모바일에서 확인하고 기존 상담·퍼널·분석·보안·SEO·뉴스·탐색·성능 검사를 실행했다. 최종 공개 반영은 해당 배포 커밋과 운영 파일 비교 결과로 확인한다. 검수는 확인한 오류와 어색한 표현을 교정하는 작업이며 모든 문장의 완전무결함을 보증하지 않는다.
