# MOKDA 홈페이지 모션 규정

## 적용 범위

- 전체 페이지의 등장 효과는 `brand-motion.js`, 메인 제품 카드 반응은 `styles/home-motion.css`, 내부 페이지 링크 반응은 `styles/site-motion.css`에서 관리한다.
- 제목·문구·사진은 모션 실행 전에도 보인다. JavaScript 또는 모션 API가 작동하지 않아도 읽기와 링크 이용을 막지 않는다.
- 글씨체, 크기, 자간, 행간과 가운데 정렬은 `WEBSITE_TYPOGRAPHY.md`를 따른다.

## 제품 카드

- 실제 `.home-product-image > img`에 확대를 적용한다. 사진 프레임과 카드의 위치·크기는 고정한다.
- 마우스를 올리면 사진을 1.035배 확대하고 제목과 기존 화살표의 색을 바꾼다. 화살표는 오른쪽 위로 3px 이동한다.
- 사진 전환은 600ms, 화살표 이동은 300ms다. 키보드 포커스에도 동일한 반응과 명확한 외곽선을 제공한다.
- 마우스 hover는 정밀 포인터에만 적용한다. 터치 화면에서는 첫 번째 탭으로 기존 제품 링크를 연다.

## 스크롤과 첫 화면

- 첫 화면은 작은 제목, 주제목, 설명, 버튼 순서로 짧은 간격을 두어 등장한다.
- 제품, 브랜드 소개, 후기, 소식, FAQ, 문의는 내용 묶음별로 한 번만 등장한다. 같은 묶음의 부모와 자식에 효과를 중복 적용하지 않는다.
- 기본 이동은 18px, 제품·소식 카드는 24px다. 재생 시간은 480–640ms, 나란한 카드의 간격은 80ms다.
- 모바일에서는 이동 거리를 65%, 재생 시간을 80%로 줄이고 카드 간 지연을 없앤다.
- 브랜드 소개 배경 사진은 고정한다. 페이지 읽기를 방해하는 반복 회전, 문구 띠, 카드 기울이기, 스크롤에 따라 움직이는 본문은 사용하지 않는다.
- 실행이 끝나면 원래 레이아웃으로 돌아간다. 키보드로 해당 묶음 안에 포커스하면 등장 효과를 즉시 종료한다.

## 내부 페이지

- 브랜드 소개는 제목·본문·사진·연혁을 각각 한 번씩 등장시킨다. 사진이나 로고가 링크가 아니면 마우스 확대 반응을 주지 않는다.
- 제품 목록의 도입 제목·문구와 두 제품의 사진·설명을 실제 DOM에 맞춰 관찰한다. 제품 상세는 스페인어의 원본 자료와 한국어·영어의 현지화 본문을 각각 적용하며 접힌 원본 자료와 그 부모를 중복 애니메이션하지 않는다.
- FAQ는 제목과 개별 항목을 적용한다. 여러 화면에 걸친 세로 항목에는 누적 지연을 주지 않는다. 나란한 카드의 지연도 최대 160ms까지만 허용한다.
- 소식 목록의 행, 기사 제목·짧은 본문·사진·갤러리는 등장 효과를 적용한다. 목록 사진과 갤러리의 작은 사진은 클릭할 수 있으므로 마우스·키보드 선택에 확대 반응을 준다. 기사 메인 사진에는 확대 hover를 적용하지 않는다.
- 문의는 제목·설명에만 등장 효과를 적용한다. 폼과 입력값, 검색창, 처리 결과와 오류 메시지, 사진 확대창, 재생 중인 영상은 위치와 투명도를 바꾸지 않는다.
- 크리에이터 컨베이어는 기존 재생을 유지하며 등장 효과를 중복 적용하지 않는다. 폐쇄된 출시응원·준비중 페이지의 홈 리다이렉트도 유지한다.

## 모션 줄이기와 검증

- `prefers-reduced-motion: reduce`에서는 등장·확대·이동 효과를 실행하지 않는다. 링크의 색과 포커스 표시로 반응을 전달한다.
- 사용 중 모션 줄이기 설정이 켜지면 진행 중 효과를 취소한다. 기본 화면을 숨겨 놓는 CSS는 추가하지 않는다.
- 한국어·스페인어·영어의 모바일·데스크탑 화면에서 중앙 정렬, 사진 프레임, 줄바꿈, 가로 넘침, 제품 링크와 키보드 반응을 확인한다.
