# 홈페이지 전환 측정

적용: 2026-10-19. 사용자 요청에 따른 퍼널 개선 기준.

| 이벤트 | 기록 시점 | 의미 |
|---|---|---|
| product_cta_click | 목록·홈·링크에서 제품 상세 또는 라인업 클릭 | 제품 탐색 의사 |
| product_detail_view | K-PEÑO·Para Carnes 상세 진입 | 제품 상세 조회 |
| chat_open | 사용자가 상담창을 열 때 | 상담 시작. 자동 세션 복원은 제외 |
| chat_intent_select | 제안 선택·사업 정보 선택·제품 상담 진입 | 상담 단계 선택 |
| chat_qualified | 국가·업종·관심 제품을 확인한 B2B 답변 완료 | 담당자 상담 준비 완료. 같은 세션·제품·국가·업종은 중복 제외 |
| whatsapp_click | WhatsApp 링크 클릭 | 외부 상담창 이동 의사. 메시지 전송·계약 완료가 아님 |
| b2b_form_start | 의미 있는 첫 텍스트 입력 | 문의 작성 시작 |
| generate_lead | 서버가 신규 문의 저장 성공을 확인한 뒤 | 실제 폼 문의 확보 |

GA4에는 이벤트명과 제품, 단계, B2B/B2C, 선택 국가, 언어·기기 등의 범주를 전달한다. 자체 수집 시트의 기존 열은 유지하며 Chat Audience, Chat Stage, Market을 끝에 추가한다. 기존 26열 시트는 헤더 작성 전에 필요한 열만 확장한다. 과거 원본 데이터는 변경하지 않는다.

대화 원문·이름·이메일·전화번호·WhatsApp 메시지 초안은 새 전환 이벤트에 보내지 않는다. 국가와 단계는 허용 목록으로 제한한다. 로컬·내부 방문 제외·verification 경로는 기존 규칙을 따른다. 일반 방문을 가장한 테스트 문의나 WhatsApp 메시지는 보내지 않는다.

GA4 탐색에서는 제품 상세 조회 → chat_open → chat_qualified → whatsapp_click을 비교한다. 별도로 contact_page_view → b2b_form_start → generate_lead를 본다. 기사 방문자는 기사 페이지뷰 → 제품 상세/사업 상담을 본다. WhatsApp 실제 전송 여부는 웹사이트 클릭만으로 확인할 수 없다. GA4 관리 화면에서 별도 전환·맞춤 측정기준 등록 여부는 이번 코드 배포와 구분한다.

기본 동선: 홈페이지의 사업 거래 선택 → 같은 단계에서 국가·업종 선택 → 관심 제품 선택. 제품 상세에서 시작하면 해당 제품을 미리 반영한다. 폼에서는 관심 제품을 확인·변경할 수 있고, 챗봇에서 넘긴 국가·업종·문의 초안을 유지한다. 이전 대화가 있는 상태에서 언어를 바꾸면 이전 문장은 보관하고 새 언어로 계속 안내한다는 표시를 한다.
## 운영 대시보드 · 2026-10-20

`대시보드`는 전체 방문 지표 다음에 상담·문의 요약을 표시한다. 상담 시작, 국가·업종·제품을 확인한 B2B 정보 확인, WhatsApp 클릭, 실제 저장된 B2B 문의는 다른 지표다.

- 상담 퍼널: 신규 측정 기간의 사이트 방문 → 상담 시작 → B2B 정보 확인 → WhatsApp 이동.
- 제품 상세 경유: 상세 조회 → 상담 시작 또는 B2B 선택으로 재개 → B2B 정보 확인 → WhatsApp 이동.
- 폼 경로: 사이트 방문 → 문의 페이지 → 실제 첫 입력 → 서버 저장 성공. 직접 진입도 포함한다.
- 영업 파이프라인: 저장된 문의의 Lead Status로만 유효 리드·상담 진행·계약을 표시한다. 클릭으로 영업 상태를 추정하지 않는다.

각 퍼널은 같은 세션의 실제 발생 시각과 이벤트 순서를 따른다. 세션당 중복 이벤트를 단계 수에 더하지 않는다. 상담 요약의 독립 집계와 모든 단계를 순서대로 거친 퍼널 수는 다를 수 있다. 소비자 제품·판매 안내는 정상 이용 경로이며 B2B 단계 미도달만으로 실패라고 단정하지 않는다.

상담 수집 기준은 2026-10-19 19:39:29 KST다. 이전 상담 단계를 소급 추정하지 않는다. 기존 폼·응원 퍼널의 수집 기준과 원본은 유지하며, 종료된 응원은 하단 과거 기록으로 구분한다.

`세부 분석`에는 제품별 상세·소식/보도 페이지, 안내 선택, 방문자가 선택한 국가별 B2B 관심을 표시한다. 국가 표는 세션의 첫 B2B 정보 확인 국가 기준 상위 10개이며 실제 수입국 실적이 아니다. 개인정보·대화 원문을 지표로 추가하지 않는다. 기간 선택·수식·유효성 검사와 원본 이벤트·리드·응원은 수정하지 않는다.

변경 검증은 `npm run test:dashboard`, `npm run test:analytics`, `npm run test:funnel`, `npm run test:security`를 사용한다. 집계 서버는 기존 Apps Script 활성 배포를 갱신해야 하며 GitHub Pages 배포만으로 시트가 갱신되지는 않는다.
