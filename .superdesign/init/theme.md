# Theme

## Compact token summary

- Brand green: `#006943` — origin, nature, trust.
- Brand orange: `#E8561D` / current UI alias `#ef5f18` — flavor, energy, movement.
- Deep brown: `#321506` — primary dark surface and display text.
- Cream: `#fff8ef` — main light surface.
- Warm sand: `#f8dfc4` / `#f7ddc2` — supporting surface and dark-section text.
- Body fonts: `Noto Sans`, `Noto Sans KR`, system sans-serif.
- Display: `Archivo Black` for Latin copy; `Noto Sans KR` for Korean display.
- Condensed labels: `Bebas Neue`.
- Layout width: mostly `max-w-7xl`; responsive padding `px-4 sm:px-6 lg:px-8`.
- Section rhythm: `py-16 sm:py-24 lg:py-28`.
- Current imagery uses 20–32px corner radii; editorial redesign should reduce card-like containers and shadows.
- Grid backgrounds are 112px square, made from subtle 1px brown or cream lines.
- Breakpoints: Tailwind defaults (`sm 640`, `md 768`, `lg 1024`, `xl 1280`, `2xl 1536`).

## Raw source references

- Tailwind configuration: `tailwind.config.ts`
- Generated utilities: `assets/mokda-tailwind.css`
- About-page custom CSS and tokens: `about.html` inline `<style>` block.

The design call includes the complete files directly so their actual implementation remains authoritative.
